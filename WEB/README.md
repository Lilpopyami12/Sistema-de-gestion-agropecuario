# AgroRastro

Demo universitaria de trazabilidad de un lote de tomate, en español.

Abre `dist/index.html` en un navegador o sirve la carpeta `dist` con un servidor estático. No requiere instalación ni compilación.

Incluye un lote con seis actividades y seis etapas de certificación ficticia. Permite registrar nuevos lotes, añadir actividades y consultar el recorrido desde la vista de consumidor. Los registros se guardan en localStorage del navegador; no se comparten entre dispositivos. Para recuperar los datos iniciales, elimina la clave `agrorastro-demo-v1` del almacenamiento del sitio.

La certificación es una simulación académica precargada, sin validez oficial. Los lotes nuevos muestran las etapas pendientes.
